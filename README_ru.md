# KARUSELKA

Быстрый турнтейбл-риг для Blender. Выберите объект, нажмите **Create Rig** —
камера летает по орбите на линейных кейфреймах, готова к скрабу и рендеру
шоурила.

Работает в паре с [LAMPOCHKA](https://github.com/abyrvalg379/lampochka):
пресет света + турнтейбл KARUSELKA = шоурил модели за две минуты.

## Возможности

- Один клик: риг + кейфреймы, работает сразу
- Два режима: **Camera** — камера летает вокруг объекта, **Object** — объект
  вращается вокруг своей оси, камера статична
- Камера рига становится активной камерой сцены (Numpad 0 и рендер);
  Remove Rig возвращает прежнюю активную
- Постоянная скорость вращения — интерполяция принудительно LINEAR
  (безье с ускорением — классическая ошибка турнтейблов)
- Авто-радиус = габарит объекта × Margin (по умолчанию 2.5, настраивается) —
  камера никогда не в упор
- Настройки камеры прямо в панели: Lens, DoF, ближний/дальний клип — правки
  применяются к камере рига сразу
- Каждый Create Rig стартует с чистых дефолтов; галка **Keep Settings**
  вместо дефолтов наследует настройки предыдущей камеры
- Авто-клипы с фиксированным соотношением 1000:1 — мелкие и крупные модели
  в кадре без артефактов глубинного буфера
- **Render Turntable** — неблокирующий рендер анимации в `//turntable/`,
  предупреждение, если в сцене нет света
- **Remove Rig** удаляет только созданное KARUSELKA; ваша камера остаётся
- Один риг за раз: повторный Create Rig пересобирает, а не плодит

## Установка

- Blender 4.2+ — Edit > Preferences > Add-ons > Install from Disk (меню-стрелка)
  > `karuselka_extension.zip`
- Blender 3.6 – 4.1 — тот же диалог, `karuselka_legacy.zip`

## Использование

1. N-панель > **KARUSELKA** > укажите Target (или просто выделите объект)
2. **Create Rig** — камера уже летает, скрабьте таймлайн
3. **Render Turntable** — рендер кадров `1..N` по указанному пути

### Параметры

| Параметр | Значение |
|----------|----------|
| Mode | Camera — облёт объекта; Object — вращается объект, камера на месте |
| Target | объект для турнтейбла (фолбэк — активный объект) |
| Camera | своя или автосозданная |
| Frames | кадров на полный оборот; fps берётся из сцены |
| Rounds | оборотов, можно дробно |
| Radius | дистанция орбиты; 0 = авто (габарит × Margin) |
| Margin | множитель авто-радиуса (по умолчанию 2.5) |
| Height | высота камеры относительно центра объекта |
| Dir | направление вращения, если смотреть сверху |
| Lens / DoF / Clip | настройки камеры рига, применяются сразу |
| Keep Settings | пересборка наследует предыдущую камеру вместо дефолтов |
| Output | путь рендера, по умолчанию `//turntable/` |

### Примечания

- Object Spin временно парентит таргет к spin-empty; Remove Rig отвязывает
  обратно с сохранением мировой трансформы.
- Render Turntable ставит диапазон сцены в `1..N` и оставляет его видимым
  в таймлайне; настройки движка, сэмплов и формата не трогаются.
- Со своей камерой KARUSELKA наводит её на цель (в режиме Camera ещё и
  парентит к pivot); Remove Rig отвязывает обратно (трансформа сохраняется).
- Кейфреймы лежат на pivot/spin-empty (`rotation_euler.z`, кадр 1 → кадр N);
  скорость меняется правкой Frames/Rounds и повторным Create Rig.
